# minesweeper

a minesweeper clone built with vanilla typescript. no frameworks, no dependencies.

## how to run

```
npm install
npm run dev
```

## controls

- **left click** — reveal a cell
- **right click** — flag/unflag a cell
- pick a difficulty, click create board, then start clicking

## difficulties

| name       | grid  | mines |
| ---------- | ----- | ----- |
| ez         | 9x9   | 10    |
| mid        | 16x16 | 40    |
| mein leben | 24x30 | 180   |
